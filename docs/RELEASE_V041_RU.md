# Проверка комплекта v0.4.1

Этот выпуск дополняет исходные материалы и делает документацию переносимой. Поведение алгоритма не изменялось.

Проверено:

- 80 существовавших файлов алгоритма, конфигурации, инструментов, тестов и сборки совпадают побайтно с предыдущим выпуском.
- Численные значения, логические результаты и структура данных во всех 78 JSON-отчётах сохранены. Редактировались только строковые метаданные путей; это явно отмечено в results/README.md.
- PDF, оригинальные Pathgraph, README организаторов и исходная переписка сверены по SHA-256 с полученными материалами.
- Внутренние Markdown-ссылки проверены; ссылка на пакет сообщений из оригинального README ведёт к пояснению его расположения в src/.
- Новый scripts/materials.py проверил SHA-256 и распаковал оба полных архива: 122 исходные учебные записи и одну запись официального примера.

Предыдущий полный прогон ROS 2 Humble с официальным checker сохраняет силу для неизменённого runtime; новая редакция документов не выдаётся за повтор этого эксперимента. Метрики: XYZ RMSE 6.114877562 м, скорость RMSE 0.056788878 м/с, 20 Гц. Данные и ограничения — в [отчёте](CHECKER_V04_RU.md).

Версия комплекта исходников и материалов — v0.4.1. Версия ROS-пакета остаётся 0.4.0, поскольку его файлы не менялись. Новые материалы и скрипт работы с архивами не участвуют в расчёте скорости и положения.
