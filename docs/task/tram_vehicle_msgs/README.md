# Определения сообщений

Ссылка из исходного README датасета ведёт сюда, поскольку в оригинальном архиве пакет находился рядом с этим README. В данном проекте полный пакет расположен в [src/tram_vehicle_msgs](../../../src/tram_vehicle_msgs/).

Он содержит оба необходимых сообщения: `VelocitySensor` и `DriverControllerCommand`. Для сборки используется только одна копия пакета из `src/`; отдельную урезанную копию из примера чекера устанавливать одновременно не нужно.
