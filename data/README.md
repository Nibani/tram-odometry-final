# Данные и самостоятельный запуск

Для сборки и работы узла достаточно клонирования репозитория: производные карты и веса включены в `src/reserve_odometry/config`. Синтетические проверки также не требуют исходных поездок.

Полные rosbag, числовой проверочный fixture, оригинальные PDF, переписка и исходные Pathgraph организаторов не включены в публичный выпуск. Все существенные условия задачи и геометрия перечислены в [описании задачи](../docs/task/README.md). Полученный от организаторов bag можно сразу воспроизвести по [инструкции жюри](../docs/JURY_RUNBOOK_RU.md).

Контрольные суммы исходных архивов сохранены в [assets.json](assets.json). При наличии архивов поместите их копии в `data/raw` под именами `training-dataset.zip` и `checker-dataset.zip`, затем выполните:

```bash
python3 scripts/materials.py verify
python3 scripts/materials.py extract
```

Для построения исходных участков карты из собственных Pathgraph используйте `scripts/restore_official_map.py --help`. Готовые карты в конфигурации дополнены геометрией конечных колец по TRAIN.
