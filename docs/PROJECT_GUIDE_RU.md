# Путеводитель по проекту

Для проверки готового решения начните с [инструкции жюри](JURY_RUNBOOK_RU.md). Сборка и синтетические тесты доступны сразу после клонирования. Для полного воспроизведения записи нужен собственный bag с разрешёнными входами и эталоном; исходный пример и числовой fixture организаторов не включены в публичный выпуск.

## Где находится код

| Каталог | Содержание |
|---|---|
| `src/reserve_odometry/` | C++-ядро, обработка входов, геометрия, ROS-узел и launch |
| `src/tram_vehicle_msgs/` | Определения сообщений |
| `config/` | Готовые карты, веса и калибровки |

| `research/legacy/` | Исторические эксперименты вне штатного пути запуска |

## Как воспроизвести результат

Для проверки выпуска **0.6** используйте ветку `main` и сохраните хеш проверяемого коммита. Соберите пакеты и выполните тесты из [инструкции жюри](JURY_RUNBOOK_RU.md). При наличии своего bag подготовьте fixture и запустите полный DDS-прогон в темпе 1×. Отчёт нужно читать вместе с покрытием, задержками и условиями запуска. [Состояние CI](https://github.com/Nibani/tram-odometry-final/actions?query=branch%3Amain).

Если архивы уже получены от организаторов, сверьте SHA-256 и распакуйте их через `scripts/materials.py` по [data/README.md](../data/README.md). Публичный репозиторий не содержит исходных архивов или ссылок на их скачивание.

Для изучения алгоритма сначала прочитайте модель и параметры. Физическое уравнение объясняет смысл ускорения; реализованный B6 использует замороженный ансамбль деревьев и проверку колёсных каналов. Масса и фактический момент отдельно не оценены. Выбор карты и редкие GNSS-поправки относятся к пространственному контуру.

Отчёты прежних версий сохранены для сравнения. Их цифры относятся к собственным входам, конфигурации и проверенному коду; они не подтверждают результат нового выпуска. Исторические журналы разработки не требуются для сборки или запуска.
