# Исторические эксперименты

Эти файлы перенесены из стартового архива как история поиска. Они не входят в воспроизводимый путь текущего решения; прежние относительные импорты и пути могут требовать исходного архива. Рабочая точка входа: scripts/reproduce.py. Старые пометки one-shot holdout относятся к исходной истории и не означают независимость нынешнего аудита.
